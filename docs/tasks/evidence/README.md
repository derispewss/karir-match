# Evidence — Fase 0

Simpan bukti kecil yang dapat di-commit di folder ini: log test, ringkasan perintah,
hash, atau tautan artefak. Artefak besar (indeks, dataset, run file) disimpan di
`artifacts/` dan tidak di-commit.

Setiap bukti harus menyebut:

- tanggal;
- perintah yang dijalankan;
- hasil ringkas;
- path atau commit yang dapat diperiksa.
